# Priminfo cached data

Generated by `npm run fetch-data` (see `scripts/fetch-priminfo-data.mjs`). These
files are committed so the app doesn't depend on live scraping/fetching at
request time or build time — re-run the script and commit the refresh when BAG
publishes new premiums (typically end of September for the following year).

- `premiums.json` — nested lookup: `kanton -> region -> ageClass -> accident -> deductible -> insurerCode -> premium`. Standard model only (`Tariftyp = TAR-BASE`); HMO/telmed/other alternative models are excluded for the MVP.
- `insurers.json` — `insurerCode -> { name, place }`, from BAG's official insurer registry.
- `regions.json` — `postcode -> { primary: { kanton, region, gemeinde }, ambiguous, candidates? }`. ~8% of postcodes span more than one canton/region (`ambiguous: true`); the current lookup just uses the first candidate.
- `market-share.json` — `kanton -> insurerCode -> average insured count`, used for the "most popular" / "best value" badges.
- `meta.json` — fetch timestamp, premium year, and source URLs.

Sources: [opendata.swiss](https://opendata.swiss/en/dataset/health-insurance-premiums) (BAG open data), [priminfo.admin.ch](https://www.priminfo.admin.ch/downloads/praemienregionen.xlsx) (premium regions), [bag.admin.ch](https://www.bag.admin.ch/de/verzeichnisse-der-zugelassenen-kranken-und-rueckversicherer) (insurer registry). No public REST API exists for this data — it's official government open data distributed as CSV/XLSX.
